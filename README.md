# Ilia Sorokin

I build developer tools and products for working with coding agents. I care about reliable execution, useful tests, and keeping engineers close to the code.

**Current work**

- [Codex Jev Native Router](https://github.com/itscloud0/codex-jev-native-router) — experimental macOS model and effort routing for Codex Desktop and CLI. Local tests pass; broad quality or subscription savings are not established.
- [ManualMode](https://manualmode.dev) — live product for practising code review and debugging alongside coding agents, including tasks from your own repository. Its [public skill](https://github.com/itscloud0/manualmode-skill) documents the agent integration.
- [Kognivu](https://kognivu.com) — live goal-to-daily-plan product.

**Open source**

- [issue-to-agent](https://github.com/itscloud0/issue-to-agent) turns GitHub issues into task packs for coding agents.
- [agent-shell-contract](https://github.com/itscloud0/agent-shell-contract) tests terminal and process behavior in agent runners.
- [action-pin-check](https://github.com/itscloud0/action-pin-check) finds mutable GitHub Actions references.
- [agent-file-integrity-litmus](https://github.com/itscloud0/agent-file-integrity-litmus) tests whether agent edits preserve bytes, newlines, encodings, and file modes.

I also contribute fixes to established Python tools: [coverage.py](https://github.com/coveragepy/coveragepy/pull/2211), [pipx](https://github.com/pypa/pipx/pull/1855), [setuptools](https://github.com/pypa/setuptools/pull/5246), [wheel](https://github.com/pypa/wheel/pull/690), and [pyproject-hooks](https://github.com/pypa/pyproject-hooks/pull/230).
